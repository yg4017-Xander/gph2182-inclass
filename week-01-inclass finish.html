1.1 Basic Arithmetic & Calculations

In the code chunk below, compute the Body Mass Index (BMI) for three study participants:

  • Participant A: Weight \(70\text{ kg}\), Height \(1.75\text{ m}\)
  • Participant B: Weight \(85\text{ kg}\), Height \(1.80\text{ m}\)
  • Participant C: Weight \(58\text{ kg}\), Height \(1.62\text{ m}\)

\[\text{BMI} = \frac{\text{weight in kg}}{(\text{height in meters})^2}\]

# Write your calculations below:
AWEIGHT <- 70
AHEIGHT <- 1.75

CWEIGHT <- 58
CHEIGHT <- 1.62
CBMI <- CWEIGHT/CHEIGHT^2
CBMI
